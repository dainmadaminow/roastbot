# Telegram Roast Bot 😈

Бот для Telegram-групп. На **каждое** сообщение участника ИИ придумывает новый короткий roast с матом, и бот отправляет его в группу реплаем. Не случайно и не только по упоминаниям.

**Важно:** добавляйте бота только в чаты, где все участники понимают, на что подписались. Бот ругается матом, а Telegram может ограничить аккаунт, если на него массово жалуются. Каждое сообщение в группе — это платный запрос к ИИ, так что в большом активном чате расходы растут быстро.

Характер бота лежит в файле `personality.txt`. Его можно менять в любой момент.

---

## Что в папке

```
telegram_roast_bot/
├── bot.py            — основной файл, запускается он
├── ai.py             — общение с ИИ
├── config.py         — чтение настроек
├── state.py          — запоминает, где бот включён/выключен
├── personality.txt   — характер бота (меняйте на здоровье)
├── requirements.txt  — список нужных библиотек
├── .env.example      — шаблон настроек
├── .gitignore
└── README.md
```

Создайте папку `telegram_roast_bot` и сохраните в неё все файлы под точно такими именами. Если используете Блокнот: «Файл → Сохранить как», в «Тип файла» выберите «Все файлы», кодировка UTF-8.

## Шаг 1. Установите Python

Нужен Python 3.10–3.13. **Python 3.14 пока не ставьте**: библиотека Telegram на нём может не заработать. Рекомендую 3.12.

**Windows**

1. Откройте https://www.python.org/downloads/ и скачайте Python 3.12.
2. В установщике **обязательно поставьте галочку «Add python.exe to PATH»**, затем нажмите Install Now.
3. Откройте PowerShell (Пуск → введите PowerShell) и проверьте:

```
python --version
```

**macOS**

```
brew install python@3.12
python3 --version
```

(Если нет Homebrew, скачайте установщик с https://www.python.org/downloads/.)

**Linux (Ubuntu/Debian)**

```
sudo apt update
sudo apt install -y python3 python3-venv python3-pip
python3 --version
```

Дальше в командах для Windows используется `python`, для macOS/Linux — `python3`.

## Шаг 2. Создайте бота в Telegram (@BotFather)

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите Start.
2. Отправьте `/newbot`.
3. Придумайте имя бота (любое, например «Жарильщик»).
4. Придумайте username: латиница, обязательно оканчивается на `bot`, например `my_roast_2000_bot`.

## Шаг 3. Получите Telegram token

После создания BotFather пришлёт сообщение со строкой вида:

```
123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Это и есть токен. Скопируйте его и **никому не показывайте**: кто знает токен, тот управляет ботом.

## Шаг 4. Получите AI API key

Бот работает с любым OpenAI-совместимым сервисом. Самый простой вариант:

1. Зайдите на https://platform.openai.com/ и зарегистрируйтесь.
2. Пополните баланс (раздел Billing), для начала хватит нескольких долларов.
3. Откройте https://platform.openai.com/api-keys, нажмите «Create new secret key» и скопируйте ключ (начинается с `sk-`). Он показывается один раз.

Альтернативы, если хотите другого провайдера: OpenRouter (https://openrouter.ai) или DeepSeek (https://platform.deepseek.com). В `.env` нужно будет поменять `AI_BASE_URL` и `AI_MODEL`, подсказки есть в `.env.example`.

> Некоторые модели могут отказываться материться или отвечать мягко. Если бот отвечает «не могу» или без мата, смените модель/провайдера или подправьте `personality.txt`.

**Windows (PowerShell):**

```
cd C:\путь\до\telegram_roast_bot
```

**macOS/Linux:**


## Шаг 6. Создайте виртуальное окружение (рекомендуется)

**Windows:**

```
python -m venv venv
venv\Scripts\activate
```

Если PowerShell ругается на «выполнение скриптов отключено», выполните один раз:

```
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
venv\Scripts\activate
```

**macOS/Linux:**

```
python3 -m venv venv
source venv/bin/activate
```

Когда всё получилось, в начале строки появится `(venv)`.

## Шаг 7. Установите зависимости

```
pip install -r requirements.txt
```

## Шаг 8. Создайте файл .env

**Windows:**

```
copy .env.example .env
notepad .env
```

**macOS/Linux:**

```
cp .env.example .env
nano .env
```

(в nano: сохранить — Ctrl+O, Enter; выйти — Ctrl+X)

## Шаг 9. Вставьте токены

В открытом `.env` впишите значения **без пробелов и кавычек** сразу после `=`:

```
TELEGRAM_BOT_TOKEN=123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
AI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

Остальные настройки можно не трогать. Главные:

| Настройка                                 | Что делает                                    | По умолчанию |
| ----------------------------------------- | --------------------------------------------- | ------------ |
| `MAX_CONTEXT_MESSAGES`                    | сколько последних сообщений группы помнит бот | 20           |
| `MIN_DELAY_SECONDS` / `MAX_DELAY_SECONDS` | пауза перед ответом                           | 1 / 3        |
| `MAX_CONCURRENT_REQUESTS`                 | сколько запросов к ИИ одновременно            | 3            |
| `AI_MODEL`                                | модель ИИ                                     | gpt-4o-mini  |
| `ADMIN_ONLY_TOGGLE`                       | `true` — /on и /off только для админов        | false        |

## Шаг 10. Запустите бота

```
python bot.py
```

(на macOS/Linux: `python3 bot.py`)

Если всё хорошо, увидите строку `Бот запущен: @имя_вашего_бота`. **Не закрывайте окно терминала**, пока бот должен работать. Остановить бота: Ctrl+C.

При следующих запусках сначала снова активируйте окружение (`venv\Scripts\activate` или `source venv/bin/activate`), затем `python bot.py`.

## Шаг 11. Настройте Privacy Mode (очень важно)

По умолчанию Telegram не показывает боту обычные сообщения в группах, только команды. Для этого бота нужно отключить Privacy Mode:

1. Откройте чат с **@BotFather**.
2. Отправьте `/mybots` и выберите своего бота.
3. **Bot Settings → Group Privacy → Turn off**. BotFather ответит, что Privacy mode disabled.
4. **Если бот уже был в группе, удалите его оттуда и добавьте заново**. Иначе Telegram продолжит применять старый режим.

Альтернатива: сделать бота администратором группы, тогда он видит все сообщения.

## Шаг 12. Добавьте бота в группу и дайте права

1. Откройте группу → название группы → «Добавить участника» → найдите бота по username → добавьте.
2. Права: боту достаточно права **отправлять сообщения** (обычное участие в группе). Админом его делать не обязательно, если Privacy Mode отключён. Если в группе участникам запрещено писать, дайте боту права администратора.
3. После добавления бот напишет приветствие.

## Шаг 13. Проверьте, что бот видит сообщения

1. Напишите в группе любое обычное сообщение (не команду), например «Привет, я сегодня проснулся в 5 вечера».
2. Бот должен показать «печатает…» и через несколько секунд ответить реплаем.
3. Если ответа нет, посмотрите в терминал. Строка `Сообщение в чате ... принято` означает, что бот сообщение видит. Если такой строки нет, проблема в Privacy Mode (шаг 11).

## Шаг 14. Команды

| Команда           | Что делает                          |
| ----------------- | ----------------------------------- |
| `/on`             | включает roast-ответы в этой группе |
| `/off`            | выключает их                        |
| `/status`         | показывает, включён ли бот          |
| `/help`, `/start` | справка                             |

В каждой группе состояние хранится отдельно и сохраняется в `data/state.json`. В новой группе бот **включён по умолчанию**. Команды `/on`, `/off`, `/status` работают только в группах.

## Как менять характер бота

Откройте `personality.txt`, измените текст, сохраните. Перезапускать бота не нужно: файл перечитывается сам.

## Если что-то не работает

| Проблема                                               | Что делать                                                                                  |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| `Ошибка настроек: Не задан TELEGRAM_BOT_TOKEN`         | Вы не создали `.env` или не вставили токен (шаги 8–9)                                       |
| `python` не найден                                     | Переустановите Python с галочкой «Add to PATH»                                              |
| Бот молчит в группе, а `/status` отвечает              | Privacy Mode (шаг 11); после изменения удалите и снова добавьте бота                        |
| В логах `Ошибка AI API: AuthenticationError`           | Неверный `AI_API_KEY` или не подходит `AI_BASE_URL`                                         |
| `Ошибка AI API: RateLimitError` / `insufficient_quota` | Закончился баланс или лимит у провайдера                                                    |
| `Ошибка AI API ... temperature`                        | Некоторые модели принимают только `AI_TEMPERATURE=1`                                        |
| ИИ отвечает пустотой или отказом                       | Используйте обычную (не «reasoning») модель, например `gpt-4o-mini`, или другого провайдера |
| В логах `Telegram просит подождать`                    | Лимит Telegram на сообщения в группе; бот сам подождёт и продолжит                          |
| Бот не отвечает после перезапуска на старые сообщения  | Так задумано: накопившееся за время простоя пропускается                                    |

Заметки по работе:

- Контекст хранится в памяти: после перезапуска бот «забывает» последние сообщения, но настройки /on и /off сохраняются.
- Если сообщений приходит больше, чем бот успевает обработать, лишние пропускаются, а устаревшие (старше `MAX_JOB_AGE_SECONDS`) не получают запоздалого ответа.
- Если ИИ временно недоступен, бот пишет ошибку в лог и продолжает работать со следующими сообщениями.
